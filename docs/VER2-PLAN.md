# Ver.2 実装設計

ベース: fb6f3ae27c6c27fe336721c15dfe9d88c172f608
開発ブランチ: feature/ver2-planning

- 生成AIは呼び出さず、4テーマ×8種類のテンプレートで企画・画像生成用プロンプトを作る。
- 純粋処理 studio-v2.js と追加画面 planner-view.js / workflow-view.js を既存エディターから分離。
- DB stamp-studio のバージョン1・projectsストア・project.version=1を維持。任意のplanningとslot.planIndexのみ追加。
- Ver.1バックアップはそのまま復元。Ver.2バックアップは企画も検証して復元。画像形式や編集履歴は維持。
- 画像読み込みは一旦保留し、01〜08の割り当てと差し替えを確認してから反映する。途中エラーでは既存画像を更新しない。
- 一括文字入れは現在の文字を既定で保持。上書きを選んでも既存の色・位置・サイズは保持する。
- 背景透過は既存エディターを利用。元画像へ戻す操作を追加し、PNG出力前に完全透明・透明部分なしの警告を行う。
- PWAのid / start_url / scope / iconsとDBは維持。新モジュールを事前キャッシュへ追加し、キャッシュのみv2.0.0へ更新。
- ChatGPTリンクに企画・画像・クエリを付けない。コピーは明示操作。アプリからの自動送信は行わない。
- mainへ直接上書きせず開発ブランチでレビュー可能にする。実機未確認の新版はmainへ自動マージしない。
